    If something goes wrong
    
            
    
              
    
                “sh2pc.exe is not the Director’s Cut build”
                
    Your exe is another version or was replaced; the Enhanced Edition’s setup swaps it, for one. Put the Director’s Cut exe back. EE packs in the sh2e folder are fine and get used.
    
              
    
              
    
                It stops partway, or the tab reloads
                
    The browser most likely ran out of memory. Close other tabs, set Workers to 1 and start again, or use the Docker packer if it keeps failing.
    
              
    
              
    
                “The browser storage is full”
                
    The zip is built in the browser’s own storage before you save it, which needs about 1.5 GB free on the disk. In Chrome or Edge you can skip that by saving straight to a folder instead.
    
              
    
              
    
                Is the result the same as the Docker packer’s?
                
    It runs the same converters. Movies come from a different ffmpeg build and look the same. With Textures set to “Same as Docker”, the full-size textures match byte for byte; the smaller mipmap levels differ slightly in both modes.
