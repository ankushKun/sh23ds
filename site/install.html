Install guide

An hour or two, mostly the packer running on its own. You need your computer, the SD card and the console.

What you need

5 min
2

Build the game data

1 to 2 h

The packer converts your copy into the formats the port reads. It only reads the game folder. Type its path and the commands follow.

The one with sh2pc.exe in it. Dragging the folder into a terminal prints its path.

That pointed inside the game folder, so the commands use the folder itself.

A leading ~ doesn’t expand inside quotes, so the commands use $HOME.

Colima only shares your home folder with Docker. Move the game inside it, or share that path in Colima.

Check your copy

TerminalPowerShell
md5 -q "/Users/you/Games/Silent Hill 2/sh2pc.exe"

It should print f3f5360298b6d0f6f2e09cf24a0925d1. Anything else is a different build, and the packer will stop.

Run the packer

Run it where you want the output. The first run downloads the packer, about 900 MB.

TerminalPowerShell
mkdir -p sd
docker run --rm \
  -v "/Users/you/Games/Silent Hill 2:/game:ro" \
  -v "$PWD/sd:/out" \
  ghcr.io/ankushkun/sh23ds-packer
“sh2pc.exe is not the Director’s Cut build”

Your exe is another version or was replaced. The Enhanced Edition’s setup swaps it, for one. Put the Director’s Cut exe back; EE packs in the sh2e folder are fine and get used.

“Mount your Silent Hill 2 folder at /game”

The path before :/game doesn’t hold sh2pc.exe and data. Keep the quotes; the name has spaces.

It stopped partway

Run the same command again. Finished steps are skipped. Add -e FRESH=1 to start over.

Docker can’t find the image

Check Docker is running (docker info). Or build the image from a clone and use sh23ds-packer as the name:

git clone https://github.com/ankushKun/sh23ds
cd sh23ds
docker build -f tools/packer/Dockerfile -t sh23ds-packer .
Without Docker

With Python 3.11+ (numpy, Pillow, pefile), ffmpeg and devkitPro’s tex3ds on your PATH, run tools/make_pack.sh "/path/to/Silent Hill 2" from a clone. It writes ./pack; copy that to sdmc:/3ds/sh23ds/.

3

Copy it to the SD card

10 min
  1. Power off the 3DS and put its SD card in the computer, or copy over Wi-Fi with ftpd.
  2. Copy the 3ds folder from sd to the root of the card. It merges with the one there.
  3. No 3ds/dspfirm.cdc? Run DSP1 once from the Homebrew Launcher. Without it the game is silent.
The card afterwards
sdmc:/
└── 3ds/
    ├── dspfirm.cdc   from DSP1
    └── sh23ds/       from the packer
        ├── bg/ chr/ demo/ events/
        ├── map/ movie/ pic/ sound/ ui/
        └── save.dat  your saves
Keep your savesThey live in 3ds/sh23ds/save*.dat. Copy them out before replacing the folder with newer data.
4

Install the app

2 min
HOME Menu (CIA)
  1. Open FBI.
  2. Remote Install, then Scan QR Code.
  3. Point the camera at the code.
sh23ds.cia

Recommended: the CIA asks a New 3DS for its fast clock, L2 cache and extra memory. No Wi-Fi? Put the file on the card and install it from FBI’s SD browser.

Homebrew Launcher (3DSX)
  1. Download sh23ds.3dsx.
  2. Copy it to sdmc:/3ds/.
  3. Start it from the Homebrew Launcher.
sh23ds.3dsx

Play

Start Silent Hill 2 from the HOME Menu. Options has the PC’s settings, the hardware profile and the button layout.

Circle Pad
Move. Rotational or Directional, in Options
B hold
Run
A
Check, open, pick up, next message

Ready the weapon and attack

Flashlight
Y
Items
Touch screen
Map, items, menus
START
Pause

New 3DS: the C-Stick strafes and turns round, ZL looks, ZR runs. Every action also works on an original 3DS. The full layouts are in CONTROLS.md.

No sound

Run DSP1 once, as in step 3.

It doesn’t get past starting up

The data must be at exactly sdmc:/3ds/sh23ds/, holding bg, chr and the rest, not another folder inside it.

It crashes or looks wrong

Please open an issue with your console model, Luma3DS version and where you were. A photo of the debug page (SELECT twice) helps.
