FAQ

Questions

Where do I get the game files?

From your own copy of the PC game. This project doesn’t host, link to or share game files.

Does it run on an original 3DS?

Yes, with a lighter profile that targets 30 fps: fewer fog sprites and streamed town tiles, no character shadows. It has been tested in Azahar’s Old 3DS model, not yet on a real console.

Is this an emulator?

No. The game’s code was rewritten in C from the PC exe and runs natively, drawing with the 3DS GPU.

Can I use my v1.0 copy?

Not yet. The converters read tables at fixed places in the Director’s Cut exe, so the packer only accepts that build.
