01 / Overview

A new engine, the same town

sh23ds is not an emulator. It's a new engine for Silent Hill 2, written in C for the New 3DS, that rebuilds the game from a study of the PC executable: the rooms and their camera roads, the lighting and the fog, the events and puzzles, the enemies, the cutscenes and every ending.

The game's own data does the rest. A converter reads your copy of the PC release and writes it out in formats the 3DS GPU understands, and the port reads them from the SD card. Nothing from the game is in this project or its downloads.

17
areas, from the town to the labyrinth
570
doors and warps, all loaded by a test
128
in-engine cutscenes
6
endings, plus Born From a Wish
  • i.

    Fog, dark and the flashlight

    Each room's lighting record from the PC exe, three lights per vertex, the PC's fog curve and its drifting fog layer, and the flashlight as a per-pixel spotlight. Dark rooms stay dark.

  • ii.

    The PC camera

    The camera module, ported function by function, follows the same camera roads through every room, with the chase, fixed and scripted cameras of the original.

  • iii.

    The whole game

    Puzzles, keys, elevators, questions, the endings and their score, the results screen, New Game+, and Born From a Wish with Maria as the player.

  • iv.

    Enemies and bosses

    Lying Figures, Mannequins, nurses, creepers on floors, walls and ceilings, Pyramid Head, the Abstract Daddy, Eddie, the Flesh Lips and Mary, with the PC's damage values.

  • v.

    Scenes and sound

    Every cutscene with its cameras, motion, faces, lights, voices and subtitles, the movies on the console, and the ADX music mixed layer by layer as on the PC.

  • vi.

    Enhanced Edition fixes

    The PS2 flashlight, the lighting and fog record fixes, draw distance, the script fixes, hold-to-stomp and more, all on by default. The full list.

04 / Install

Add it to your 3DS

  • Console

    A New Nintendo 3DS, New 3DS XL or New 2DS XL. The original models don’t have the speed or memory.

  • Firmware

    Luma3DS with FBI or the Homebrew Launcher. Not set up yet? Follow 3ds.hacks.guide first.

  • The game

    Your own copy of Silent Hill 2 for PC, Director’s Cut, unmodified.

  • Space

    About 1.4 GB free on the SD card, and a computer with Docker.

  1. Build the game data

    Run the packer on your Silent Hill 2 folder, as shown below. You get a folder called 3ds.

  2. Copy it to the SD card

    Put that 3ds folder at the root of the card. It merges with the one already there and adds 3ds/sh23ds/.

  3. Dump the DSP firmware

    Run DSP1 once if you never have. It writes 3ds/dspfirm.cdc, and without it the game plays in silence.

  4. Install the app

    Scan the code with FBI, or download the file and install it yourself. Then start Silent Hill 2 from the HOME Menu.

HOME Menu app (CIA)

  1. Open FBI on your 3DS.
  2. Choose Remote Install, then Scan QR Code.
  3. Point the camera at this code and confirm.
sh23ds.cia

Recommended. The CIA asks the system for the 804 MHz clock, the L2 cache and the 124 MB memory mode the port is made for.

Homebrew Launcher (3DSX)

  1. Download sh23ds.3dsx.
  2. Copy it to sdmc:/3ds/ on the SD card.
  3. Start it from the Homebrew Launcher.
sh23ds.3dsx

The 3DSX runs at whatever clock and memory mode the launcher was started with, so the CIA is the better choice on a console.

Checksums are in sh23ds.sha256. Older versions are on the releases page.

05 / Game data

Your copy, converted

The packer reads your Silent Hill 2 folder, the one with sh2pc.exe and data, and converts every room, texture, character, event, picture, sound and movie into the formats the port reads. It never changes the game folder.

It runs in a container with everything it needs, so Docker is the only thing to install. The image holds the converters from this project and nothing from the game.

~1 h
on a laptop, mostly textures
1.4 GB
written for the SD card
1
exe it accepts, checked by MD5

macOS and Linux

$ mkdir sd
$ docker run --rm \
    -v "/path/to/Silent Hill 2:/game:ro" \
    -v "$PWD/sd:/out" \
    ghcr.io/ankushkun/sh23ds-packer
  • On Linux, add --user "$(id -u):$(id -g)" after --rm so the files are yours.
  • With Colima on macOS, keep the game and the output folder inside your home folder.

Windows (PowerShell)

PS> mkdir sd
PS> docker run --rm `
    -v "C:\Games\Silent Hill 2:/game:ro" `
    -v "${PWD}\sd:/out" `
    ghcr.io/ankushkun/sh23ds-packer
  • Use Docker Desktop with the WSL 2 backend, and put your game’s folder in the first -v.

From a clone

# the same image, built from the source
$ git clone https://github.com/ankushKun/sh23ds
$ cd sh23ds
$ docker build -f tools/packer/Dockerfile -t sh23ds-packer .
$ docker run --rm -v "/path/to/Silent Hill 2:/game:ro" \
    -v "$PWD/sd:/out" sh23ds-packer

# or without Docker: Python 3.11+ (numpy, Pillow, pefile),
# ffmpeg and devkitPro's tex3ds on your PATH
$ tools/make_pack.sh "/path/to/Silent Hill 2"

Which copy works

The packer accepts the retail Director’s Cut sh2pc.exe (MD5 f3f5360298b6d0f6f2e09cf24a0925d1) and stops on anything else, because the converters read tables at fixed places in that exe. If you installed the Enhanced Edition on your PC copy, point the packer at a clean install instead: its fixes are already in the port.

07 / Develop

Build it, break it, fix it

Build from source

Everything builds in containers with pinned images, so Docker is all you need.

$ git clone https://github.com/ankushKun/sh23ds
$ cd sh23ds
$ ./port/build.sh     # devkitARM: port/sh23ds.3dsx
$ ./port/package.sh   # makerom: sh23ds.cia, then dist/

Pushing a tag that matches VERSION builds, checks and publishes the release and the packer image.

Test without a console

The port runs in Azahar with the system set to New 3DS and the game data in its virtual SD card. On macOS, tools/lr3ds runs builds headlessly in Azahar’s libretro core with scripted buttons and screenshots, and tools/lr3ds/smoke.sh walks eleven scenes from the title to a save point.

The debug file

Lines in sdmc:/3ds/sh23ds/debug.txt change how the game starts. Delete the file to play normally.

08 / FAQ

Questions

Where do I get the game files?

From your own copy of the PC game. This project doesn’t host, link to or share game files, and requests for them in Issues will be closed.

Does it run on an original 3DS or 2DS?

No. The port relies on the New 3DS’s faster clock, its L2 cache and its extra memory. Without them the game wouldn’t fit, let alone keep up.

Can I use the v1.0 release, or a copy with the Enhanced Edition?

Not yet. The converters read data at fixed places in the Director’s Cut exe, so the packer only accepts that build. The Enhanced Edition’s fixes are already part of the port.

Why does building the data take so long?

Most of the time goes into compressing thousands of textures to ETC1 with mipmaps at the encoder’s highest quality, which keeps the console’s memory and bandwidth free for everything else. You only do it once.

Where are my saves?

In sdmc:/3ds/sh23ds/save.dat, with your options in options.txt next to it. Back them up before you replace the game data folder.
