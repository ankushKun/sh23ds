                Help
                
        
                  
        
                    
        It says sh2pc.exe is another version
        You need the 2002 Director’s Cut, not version 1.0 or 1.1. If a fix replaced your sh2pc.exe, put the original back, or next to it as sh2pc.bak.
        
                    
        It stops partway, or the tab reloads
        Close other tabs, set Workers to 1 in Options and start again.
        
                    
        It runs out of room for the zip
        It needs about 2 GB free. In Chrome or Edge, set Save as to Folder in Options and pick the SD card.
        
                    
        Something else
        Open an issue and say which 3DS you have.

      Questions
      
        
      
          
      
            
      Where do I get the game?
      
            
      You need the 2002 PC Director’s Cut, also known as Silent Hill 2: Restless Dreams. It isn’t sold anymore, but MyAbandonware has it; download the Full Rip version.
      
          
      
          
      
            
      Does it run on an original 3DS?
      
            
      Yes, with lighter settings that aim for 30 fps.
      
          
      
          
      
            
      Is this an emulator?
      
            
      No. The game’s code was rewritten to run on the 3DS itself.
      
          
      
          
      
            
      Is this the 2024 remake?
      
            
      No, it’s the 2001 game.
